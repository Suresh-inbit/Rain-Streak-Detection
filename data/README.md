# Data

This directory is where the assignment's image sets should be placed. The
actual images are not committed to the repository (they are course-provided
and/or large binary files) — download them from the links given in the
assignment and place them as described below.

```
data/
├── raw/                     # "Single Rain Images" (no ground truth) — inputs for detect.py
├── validation/
│   ├── images/               # validation rainy images
│   └── gt_masks/              # corresponding ground-truth rain masks (same filename stem)
└── synthetic_demo/           # auto-generated by scripts/generate_synthetic_demo.py
    ├── images/
    └── gt_masks/
```

## 1. Single rain images (qualitative development set)

Download the images from the "Single Rain Images" link provided in the
assignment and place them in `data/raw/`. Run the detector on them with:

```bash
python scripts/detect.py --input data/raw --output results/raw --overlay
```

## 2. Validation set (quantitative evaluation, IoU)

Download the validation images and their ground-truth rain masks from the
"Validation set" link provided in the assignment. Place the rainy images in
`data/validation/images/` and the corresponding ground-truth masks in
`data/validation/gt_masks/`, using the **same filename stem** for an image
and its mask (e.g. `rain_003.jpg` <-> `rain_003.png`).

Then compute the IoU score with:

```bash
python scripts/evaluate.py \
    --images data/validation/images \
    --gt-masks data/validation/gt_masks \
    --output results/validation
```

This prints per-image IoU/Precision/Recall/F1 plus the mean IoU across the
validation set, and (with `--output`) saves predicted masks, overlays and a
`metrics.csv` summary.

## 3. Synthetic demo (no download needed)

Because the real datasets above aren't bundled with the repo, a small,
self-contained synthetic demo is included so the pipeline can be sanity
checked immediately:

```bash
python scripts/generate_synthetic_demo.py --output data/synthetic_demo
python scripts/evaluate.py \
    --images data/synthetic_demo/images \
    --gt-masks data/synthetic_demo/gt_masks \
    --output results/synthetic_demo
```

This generates a procedurally-rendered scene with synthetic rain streaks
drawn on top of it, together with the exact mask used to draw them, and
reports IoU against that ground truth. See the main [README](../README.md)
for example results.
